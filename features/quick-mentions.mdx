## How @ Mentions Work

### Basic Usage

Simply type `@` in the chat input and you'll see a dropdown with available options:

```
@web search for latest AI news
@chart create a bar chart from this data
@agent connect me to the sales agent
@preset generate a meeting summary
```

### Smart Suggestions

As you type, the system provides intelligent suggestions:

- **Fuzzy Matching**: Find tools even with typos or partial names
- **Context Awareness**: Prioritize relevant tools based on conversation
- **Recent Usage**: Show frequently used tools at the top
- **Category Grouping**: Organize suggestions by tool type

## Advanced @ Mention Features

### Parameter Handling

Pass parameters to @ mentions for dynamic functionality:

```
@chart create bar chart from [data] with title "Sales Q4"
@web search for [query] in [language] with [date range]
@agent sales help with [lead type] for [company size]
```

### Chaining @ Mentions

Combine multiple @ mentions for complex workflows:

```
@web search for AI trends → @chart create timeline → @preset generate report
@agent research gather data → @agent analysis process results → @agent writing create summary
```
