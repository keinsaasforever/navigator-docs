## What are System Prompts?

System prompts are instructions that define how your AI assistant behaves, responds, and interacts with you. They act as the "personality" and "knowledge base" for your AI assistant, shaping its responses to match your preferences and requirements.

## Custom Instructions for MCP Tools

### MCP Server Instructions

<AccordionGroup>
  <Accordion icon="server" title="Server-Level Instructions">
    **Set default context for entire MCP servers**:
    
    - Avoid repetitive information
    - Set consistent behavior across tools
    - Define server-specific preferences
    - Configure error handling approaches
    
    **Example**: "When using the database server, always include query execution time in responses"
  </Accordion>
  <Accordion icon="wrench" title="Tool-Specific Instructions">
    **Customize individual tool behavior**:
    
    - Set default parameters
    - Define output formatting
    - Specify error handling
    - Configure validation rules
    
    **Example**: "When using the chart tool, always use the company color scheme and include data source citations"
  </Accordion>
</AccordionGroup>

### Tool Usage Guidelines

<AccordionGroup>
  <Accordion icon="list" title="Usage Preferences">
    **Define how tools should be used**:
    
    - **Priority**: Which tools to prefer for specific tasks
    - **Combinations**: How tools should work together
    - **Fallbacks**: What to do when preferred tools aren't available
    - **Validation**: How to verify tool outputs
    
    **Example**: "For data analysis, always use the Python executor with pandas, and create visualizations with the chart tool"
  </Accordion>
  <Accordion icon="shield" title="Error Handling">
    **Customize error responses**:
    
    - How to handle tool failures
    - What information to provide when errors occur
    - When to retry vs. when to suggest alternatives
    - How to communicate technical issues to users
    
    **Example**: "When a tool fails, explain what went wrong in simple terms and suggest alternative approaches"
  </Accordion>
</AccordionGroup>

## Best Practices

### Effective Customization

<AccordionGroup>
  <Accordion icon="lightbulb" title="Start Simple">
    Begin with basic preferences, then add MCP customizations as you use specific tools regularly.
  </Accordion>
  <Accordion icon="target" title="Be Specific">
    The more detailed your instructions, the better the assistant can help. Instead of "be helpful," try "explain technical concepts with real-world examples."
  </Accordion>
  <Accordion icon="test-tube" title="Test and Iterate">
    Use the tool testing feature to see how your customizations affect tool behavior before using them in important chats.
  </Accordion>
  <Accordion icon="handshake" title="Project Synergy">
    Combine personal preferences with project-specific instructions for domain expertise (e.g., "React developer" + "E-commerce project context").
  </Accordion>
</AccordionGroup>

### Common Mistakes to Avoid

- **Over-customization**: Too many specific instructions can confuse the assistant
- **Inconsistent Instructions**: Conflicting instructions lead to unpredictable behavior
- **Ignoring Context**: Not considering how instructions work in different situations
- **Not Testing**: Failing to test customizations before using them in important conversations
- **Static Settings**: Not updating preferences as your needs change

- **Conditional Instructions**: Use if/then logic for different scenarios
- **Template Instructions**: Create reusable instruction templates for different use cases
- **Feedback Loops**: Use feedback to continuously improve customizations
- **A/B Testing**: Test different instruction sets to find what works best
- **Documentation**: Keep track of what customizations work well for future reference

## Troubleshooting

### Common Issues

<AccordionGroup>
  <Accordion icon="exclamation-triangle" title="Instructions Not Working">
    **If customizations aren't taking effect**:
    
    - Check for conflicting instructions
    - Verify instructions are saved properly
    - Test with simple examples first
    - Review instruction syntax and clarity
  </Accordion>
  <Accordion icon="question" title="Unexpected Behavior">
    **If the assistant behaves unexpectedly**:
    
    - Review recent instruction changes
    - Check for ambiguous instructions
    - Test individual instruction components
    - Reset to basic settings and rebuild gradually
  </Accordion>
  <Accordion icon="cog" title="Tool Integration Issues">
    **If MCP tools aren't working as expected**:
    
    - Verify tool-specific instructions
    - Check tool availability and permissions
    - Test tools independently
    - Review tool configuration settings
  </Accordion>
</AccordionGroup>
