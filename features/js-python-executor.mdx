## What is the Code Executor?

The JS,PYTHON Executor allows you to run JavaScript and Python code directly within your AI conversations. It's designed for quick calculations, data analysis, automation tasks, and rapid prototyping without needing external development environments.

### Code Execution Examples

<AccordionGroup>
  <Accordion icon="calculator" title="Mathematical Calculations">
    **JavaScript Example**:
    ```javascript
    // Calculate compound interest
    function compoundInterest(principal, rate, time) {
        return principal * Math.pow(1 + rate, time);
    }
    
    const result = compoundInterest(1000, 0.05, 10);
    console.log(`Compound interest: $${result.toFixed(2)}`);
    ```
    
    **Python Example**:
    ```python
    # Statistical analysis
    import statistics
    
    data = [85, 90, 78, 92, 88, 76, 95, 89, 84, 91]
    mean = statistics.mean(data)
    median = statistics.median(data)
    std_dev = statistics.stdev(data)
    
    print(f"Mean: {mean:.2f}")
    print(f"Median: {median}")
    print(f"Standard Deviation: {std_dev:.2f}")
    ```
  </Accordion>
  <Accordion icon="chart-bar" title="Data Analysis">
    **Python Data Analysis**:
    ```python
    import pandas as pd
    import matplotlib.pyplot as plt
    
    # Create sample data
    data = {
        'Month': ['Jan', 'Feb', 'Mar', 'Apr', 'May'],
        'Sales': [100, 120, 110, 140, 130],
        'Expenses': [80, 85, 90, 95, 88]
    }
    
    df = pd.DataFrame(data)
    df['Profit'] = df['Sales'] - df['Expenses']
    
    print(df)
    print(f"Total Profit: ${df['Profit'].sum()}")
    ```
  </Accordion>
  <Accordion icon="web" title="Web Scraping">
    **Python Web Scraping**:

        print(heading.get_text().strip())
