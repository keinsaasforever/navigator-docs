## Using Web Search

### Basic Search Commands

<AccordionGroup>
  <Accordion icon="at" title="@web Mentions">
    **Use @web for direct search**:
    
    - `@web search for [query]`
    - `@web find information about [topic]`
    - `@web look up [specific information]`
    - `@web research [subject]`
  </Accordion>
  <Accordion icon="chat" title="Natural Language">
    **Ask questions naturally**:
    
    - "What's the latest news about climate change?"
    - "Find me information about machine learning trends"
    - "Look up the weather in Tokyo"
    - "Research the history of artificial intelligence"
  </Accordion>
  <Accordion icon="cog" title="Advanced Queries">
    **Use advanced search syntax**:
    
    - `"exact phrase"` - Search for exact phrases
    - `site:example.com` - Search within specific sites
    - `filetype:pdf` - Search for specific file types
    - `before:2024-01-01` - Search within date ranges
  </Accordion>
</AccordionGroup>

  <Accordion icon="repeat" title="Iterate and Refine">

### Research Quality

- **Use Multiple Sources**: Cross-reference information from different sources
- **Check Dates**: Ensure information is current and relevant
- **Evaluate Credibility**: Consider source authority and reputation
- **Look for Patterns**: Identify trends and patterns across sources
- **Question Assumptions**: Be critical of information and seek verification
